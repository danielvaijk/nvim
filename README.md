# Neovim Config

## Keymaps

Leader is `<Space>`.

### File Operations

| Keymap | Action |
| --- | --- |
| `<leader>w` | Write buffer |
| `<leader>q` | Quit |
| `<leader>wq` | Write buffer and quit |
| `<leader>wa` | Write all changed buffers |

### File Explorer

| Keymap | Action |
| --- | --- |
| `<leader>e` | Toggle nvim-tree |
| `<leader>fe` | Reveal current file in nvim-tree |

### Telescope

| Keymap | Action |
| --- | --- |
| `<leader>ff` | Find files |
| `<leader>fg` | Live grep |
| `<leader>fb` | List buffers |
| `<leader>fh` | Search help tags |
